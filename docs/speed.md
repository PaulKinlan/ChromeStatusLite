# Gate speed and coverage

- Fast budget: <=60 s. `tools/fast-gate.sh` maps changed paths to offline route/client suites; unmapped paths fail. Common renderer/handler/static style/config changes select all suites. A zero-diff tree still runs all suites. No server starts on import. Dependencies are cached (`--cached-only`), so an uncached checkout fails rather than quietly reaching the network.
- The fast gate then ALWAYS runs `tests/http_smoke_test.ts` in a second, wider-sandboxed `deno test` invocation (same permissions as the full gate's smoke run). A changed test file is only 'placed' in fleet-check coverage by its own execution, and shared modules (`src/handler.ts`, `tests/fixture.ts`) count the smoke suite as a covering candidate — without it every fast verdict reported PARTIAL coverage (chrome-status-lite-tor). It is offline, fixture-backed and ~2 s. Harness/infra paths no test imports by name (`tools/*`, `main.ts`, `src/flora.ts`, `src/types.ts`, `src/stream-utils.ts`, `src/ui-components/*`) are attributed to the executed suites via `.fleet/coverage-contract.json`, which must stay in sync with the mapping in `tools/fast-gate.sh`.
- Full budget: <=300 s. `tools/full-gate.sh` runs all offline suites plus a fixture-backed real HTTP listener, redirect/static/404 checks and a headless Chrome DOM + screenshot check. The browser's stylesheet request status is observed at the HTTP listener, with an isolated negative fixture proving that a CSS 404 is caught. Only the merger runs this tier on the merged union.
- First local focused measurement (2026-10-17, Deno 2.9.7, cached dependencies): fast affected set 8 assertions / ~0.5 s Deno reported; HTTP/browser smoke 1 assertion / ~1 s Deno reported. After the stylesheet-negative fixture (review finding chrome-status-lite-8aa), the focused browser test took ~2 s locally (two browser visits). With chrome-status-lite-tor the fast gate always includes the smoke suite: fast total ~2.5 s wall on this VM (route suites ~0.5 s + smoke ~2 s). These are development samples, **not** a fleet-check median. Coord installs host `CHECK_FAST_CMD=bash tools/fast-gate.sh` and `CHECK_CMD=bash tools/full-gate.sh`; remeasure cached PASS samples and use `fleet-budget` before claiming either budget met.
- Route fixture suites are independent and never call upstream. Client fixture injects a fetcher and cache controlled by a local clock; it does not touch the process singleton. Browser creates and closes its own server/profile. No test reads another test's generated files.
